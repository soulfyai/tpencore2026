# 臺北城市內容與構圖樣板

使用者指出上一輪的差距首先是場景內容與構圖：示意圖有校園操場、湖泊、橋、碼頭、帆船與客船；只增加建築立面細節，無法補足這些缺少的生活場景。

因此新增獨立的 [taipei-composition.html?v=2](https://soulfyai.github.io/tpencore2026/taipei-composition.html?v=2)，以可360°旋轉的完整城市空間配置內容，預設鏡頭僅為進入城市的起點。正式網站、四市預覽與上一輪材質樣板均不替換。

湖泊四周配置住宅、商店、步道及公共設施，建築因所在位置朝向湖岸或街道；不再為固定鏡頭清空湖前住宅。使用者轉動時，建築、湖面、橋與碼頭自然地交替遮擋、露出。住宅、101、辦公樓、校舍與照護中心補齊背面及側面立面；兩側橋頭與湖岸店宅補上步道連接。101仍為全城最高地標。草地、樹木及步道填補場景間的關係，而非僅把相同建築排滿。六艘船包含三艘客船、三艘帆船；水域與橋均為實際幾何，未使用生成圖片代替。

`taipei-composition-elements.js` 提供具名稱及座標的場景清單，供逐項檢視是否落實參考圖內容。標牌為場景類別，並非新增政策承諾或聲稱實際建築位置；整座島、碼頭及航線均為美術示意。

`tools/check_taipei_composition.py` 檢查內容清單、船隻、原生操作、全貌國旗取景、90°／180°／270°四向環看、360°回到原位、旋轉時目標與距離不變、日／夕陽、畫質及桌機手機實拍。布局檢查保留海岸、道路與建築碰撞限制，刪除「湖前必須無建築」的錯誤限制。截圖在 `out/composition-*.png`。`package_site.py` 只加入新預覽檔案，VERSION維持原值，NAS原更新器不下載新預覽檔。
