# 臺北城市內容與構圖樣板

使用者指出上一輪的差距首先是場景內容與構圖：示意圖有校園操場、湖泊、橋、碼頭、帆船與客船；只增加建築立面細節，無法補足這些缺少的生活場景。

因此新增獨立的 [taipei-composition.html?v=1](https://soulfyai.github.io/tpencore2026/taipei-composition.html?v=1)，優先將內容放進同一個臺北主視角。正式網站、四市預覽與上一輪材質樣板均不替換。

| 參考圖內容 | 本輪配置 | 驗收視角 |
| --- | --- | --- |
| 校園與操場 | 左前側低樓校舍、橢圓多線跑道、球場、球門、看台與燈柱 | 臺北主視角、校園操場 |
| 湖與橋 | 前景中央不規則湖泊、木拱橋、棧板及步道 | 臺北主視角、湖橋碼頭 |
| 港灣生活 | 左前岸碼頭、候船建築、停靠及水上客船 | 臺北主視角、湖橋碼頭 |
| 帆船 | 左側、前景、右側三艘具真實三角帆幾何的帆船 | 臺北主視角、湖橋碼頭 |
| 高低混合城市 | 在原七組建築外增加23組不同高度、色彩及朝向的生活建築，另有校舍與照護中心 | 臺北主視角、街區生活 |
| 城市連結 | 右後側白色拱橋接到局部岸邊，作為周邊連結的視覺暗示 | 臺北主視角 |
| 地標焦點 | 101位於後景，為最高建築，頂端保留中華民國國旗 | 臺北主視角 |

前景以水、船與沿岸生活為主，中景由校園、托育、照護及住宅穿插，後景由101與玻璃高樓形成天際線。草地、樹木及步道填補場景間的關係，而非僅把相同建築排滿。六艘船包含三艘客船、三艘帆船；水域與橋均為實際幾何，未使用生成圖片代替。

`taipei-composition-elements.js` 提供具名稱及座標的場景清單，供逐項檢視是否落實參考圖內容。標牌為場景類別，並非新增政策承諾或聲稱實際建築位置；整座島、碼頭及航線均為美術示意。

`tools/check_taipei_composition.py` 檢查內容清單、船隻、原生操作、全貌國旗取景、四視角、日／夕陽、畫質及桌機手機實拍。截圖在 `out/composition-*.png`。`package_site.py` 只加入新預覽檔案，VERSION維持原值，NAS原更新器不下載新預覽檔。
