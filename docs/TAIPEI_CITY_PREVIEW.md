## 實際內容

沿用 `taipei-preview-data.json` 的臺北島輪廓、正規化地標位置與政策資料，保留17主題（9政見／8政績）、16地標及62條目／原始引用。展示尺度改為每資料單位14場景單位，給非等大街區足夠空間；地標間相對位置不變，並非真實比例導航。臺北101仍為最高地標，頂部保留國旗。

相鄰基地合併成多翼住宅、狹長園區與校園，移除26段內部道路，形成23個跨基地街廓（含政策與湖岸）。保留已核准天際線範例的玻璃雙塔、曲面、Art Deco、退台等語彙，再以尺度調整放入臺北島；共96筆建築／建築群紀錄，並非96個政策建案。

四處大小、長寬與凹灣不同的池湖實際切開草地，保留較低水位、草岸／步道、蘆葦礫岸及一座木橋。普通樹群避讓水域、道路及建築；自然地標植栽依原地形高度安放。

## 政策與建築的對應

`POLICY_SCENES` 用政策ID明確對應，新增主題未映射時直接報錯，避免一律套用同一公共館。政見與同類政績共用建築語彙，但保留不同條目與清單分組。

| 類別 | 場景與可辨識設施 |
|---|---|
| 交通 | 車站入口、候車棚、月台、公車 |
| 居住與都更 | 錯位住宅塔樓、連接裙樓、公共內院 |
| AI產業 | 科技研發樓、實驗室、空橋、太陽能 |
| 育兒托育 | L形托育館、滑梯、遊戲庭院、家長與孩童 |
| 教育與營養午餐 | 教學樓、學習館、餐廳、活動場地 |
| 銀髮照顧／社福 | 日照或社區服務、實際斜坡入口、遮蔭座椅 |
| 運動／體育 | 橢圓跑道、球場、看台／室內運動館 |
| 青年 | 共創工作室、自行車架、交流遮棚與露台 |
| 無菸與食安 | 食安檢驗室、市場攤架、無菸標示，並非一般醫院 |
| 環境循環 | 分類設施、水槽與太陽能屋頂 |
| 文化觀光 | 紅磚拱廊、展覽館、雕塑廣場 |
| 其他公共服務 | 服務大廳、綠化廣場 |

政策面板保留原條目與來源，另解釋該建築的示意關聯，明示不代表落實情形或真實位置。拾取體分別跟隨建築各翼，空地點選限定在政策街廓內。

## 人車動態

89位民眾（含不同尺度的孩童、灰髮長者與手杖）、26輛行駛車輛，另有交通站內停靠公車。人行道與兩處湖岸步道有步行路線；車輛只走保留的車行道路，採靠右車道、圓角路口與時間差更新，不會從一個基地瞬移到另一處。

使用重複幾何／材質的動態InstancedMesh，移動時更新真正的instanceMatrix，包含行走擺臂／步態。這是示意循環，不是即時人流或完整交通號誌模擬。

右上角「動態」可暫停／繼續，民眾與車輛仍保留在畫面。預設播放；系統要求減少動態時，預設暫停，使用者可明確開啟。分頁恢復時限制時間步長，暫停不累積快轉；沒有新增Cookie、帳戶、任務紀錄或統計請求。
