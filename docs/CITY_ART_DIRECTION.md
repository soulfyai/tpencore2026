# 城市美術升級規格：草地、植栽與生活街景

日期：2026-10-25｜狀態：設計規格，尚未套用線上場景。

依據：使用者提供的城市建設遊戲日景與夕景參考。以地面、植栽、道路、建築與光影連成完整城市為標準，不能只精製任務街角或單一地標。參考不代表複製原遊戲素材、UI、廣告或商標。

## 目標

一般未建築空地以綠色草地為基底，樹木有自然疏密與成群分布；城市建物落在有用途的基地上，道路、入口、廣場、停車與綠地有清楚銜接。保留四市輪廓、政策資料、方形街廓、霓虹品牌與現有操作。

目前已有 turf 材質、樹木及公園配置，但不足以代表目標完成。需要處理全島地表覆蓋、空地用途、植栽分布及細節層級，而非單純提高樹木數量或把灰地改綠。

## 地面分區

| 用地 | 地面與細節 |
|---|---|
| 普通空地／預留地 | 連續草地，大尺度深淺色變化與細微紋理；部分保留開闊草坪，不全部塞樹 |
| 住宅 | 中庭、庭院與草地，入口銜接人行道，低矮灌木和局部喬木 |
| 學校／托育／醫療 | 建築前庭、必要鋪面、可到達入口與植栽緩衝；遊具、座椅等依場景用途配置 |
| 商業／行政 | 人行廣場、樹穴與綠帶；保留有理由的硬鋪面，不全部綠化 |
| 工業／科技 | 工作與裝卸區硬鋪面，邊界綠帶；不得把工作動線變成草地 |
| 道路／高架邊緣 | 人行道、路緣、中央分隔或邊界植栽；橋下依空間條件處理，不把整座橋下塗成草地 |
| 公園與自然邊緣 | 草坪、成群樹林、步道與休憩節點；既有沙灘、碼頭、岩岸及水面保留 |

不沿每一格畫同樣綠色邊框，不讓相鄰草地的紋理方向與接縫暴露格網。大尺度色塊用於打散重複，小尺度細節只在近景明顯；避免規律棋盤格與高對比雜訊。

## 植栽分布：有規則的自然感

- 同一位置使用固定種子生成，重載、轉動鏡頭與切日夜不重新抽樹，不因 LOD 改變位置。
- 先定用地及禁止種植區，再採有最小間距的取樣；加入低頻密度場形成樹群、林緣及開闊空間。
- 至少區分圓冠喬木、較高細冠／針葉輪廓、灌木三種層次，依城市區域配置，非全域平均亂混。
- 在合理範圍內變化樹高、冠幅、朝向與葉色；同一區維持協調色系，非每棵不同高飽和色。
- 公園與自然邊緣成群；住宅有庭園；商業及主街行道樹可較有秩序。自然感與規劃感依場景分配。
- 以實際建築 footprint、道路寬度、路口視線、步道、入口、地標基座及任務互動區作避讓；不能只檢查樹幹點，樹冠也要預留空間。
- 不在海面、沙灘主通道、軌道、碼頭工作區或建築內生成樹；與任務路徑使用同一占用資料，避免角色穿樹。

## 建築與街道細節

- 建物要有與用途相符的入口、門窗層次、屋頂設備及基地銜接，不以大量細線替代造型。
- 住宅、商辦、學校、醫療、工業各自有材質與基地配置，避免同一模型換色反覆鋪滿。
- 人行道、路緣、標線與過街處尺度一致；停車格與車道僅在實際有空間的基地安排。
- 路燈、座椅、遊具、垃圾桶、站牌採少量有用途的配置，不在所有街角蓋同一套裝飾。
- 通用裝飾不代表真實設施位置；政策提案不得因美術新增就標示為已完成設施。

## 光影與材質

日景需辨認樹冠、屋簷與建築落影；夕景為同一場景的光照變化。草地、樹葉、牆面、玻璃與柏油有不同粗糙度與反光，不全靠發光或高飽和色增加存在感。

近景樣板先驗證實際陰影與接觸感，再決定全城採即時／烘焙／簡化陰影的組合；不要先承諾手機上每棵樹都有即時陰影。避免陰影粉刺、共面草地貼片與海岸深度閃爍。

## 顯示距離與手機

- 近景：人物、入口、植栽、材質與接觸陰影可辨認。
- 中景：建築體積、樹群與街道用途清楚；縮減細小零件。
- 全景：保留完整綠地覆蓋與樹群輪廓，細節按距離簡化，不讓島嶼退回大面積空白灰地。
- 植栽幾何與材質共用，優先 InstancedMesh，避免每棵樹獨立 draw call。LOD 過渡穩定，不在鏡頭緩動時反覆跳出。
- 用實機量測 frame time、draw calls、三角形、記憶體與長時間旋轉穩定性，再決定密度，不靠桌面軟體渲染截圖推斷手機效能。

## 實作順序與驗收

1. 保留現版日景／夕景／手機效能基準；建立土地用途與不可占用範圍。
2. 做臺北的一個代表區：住宅空地、普通草坪、樹群、主街、公共設施與任務街角，先驗證同一標準能處理一般空地與任務近景。
3. 檢查日景、夕景、夜景；用相同鏡頭比較，允許旋轉、縮放、走路，不限固定美化角度。
4. 驗證入口、路口、過街與任務路徑無植栽阻擋；固定種子、無地面／陰影閃爍、無海上樹木。
5. 使用者認可實際可操作場景後，擴到整個臺北；再按四市場景用途分配密度及樹種，非四次複製同一張貼圖。
6. 全景、中景、人物近景都需檢查；桌機與手機至少各一個實機驗證，效能不達標先優化再擴量。
