# 橋梁與海空交通預覽 v0.4.6

入口 `greater-taipei-v0.4.6.html`；`?view=bridges` 直接檢視雙橋。延續 v0.4.5 美術與兩座島配置，不取代正式網站。

## 橋梁

補回關渡大橋和淡江大橋：前者以三段紅色鋼拱、雙側拱肋、吊桿與橫向支撐辨識；後者使用白色單塔、傾斜曲線塔柱與雙向扇形斜張纜索。兩者均有連續橋面、護欄、分道線、橋墩、照明及橋上車流，共 16 輛車。

橋頭固定接上兩市既有道路節點；橋面兩端由地面逐步升高。規劃時保護既有政策設施、公園與自然地標，並在植樹與補建築之前預留接岸走廊。橋名沿用地標標籤系統，依「地標」開關顯示。

目前仍是經確認的雙島示意配置。兩座橋的位置、長度與比例配合這個場景，並非真實河道或工程測繪位置。

## 船舶與飛機

- 船隻 **4 → 24 艘**：保留四艘原有客船／帆船，再增兩市各十艘。新增船型包含渡輪、帆船、漁船、貨櫃船與拖船，沿不同水域航線行駛並帶船尾水痕。
- 飛機 **2 → 8 架**：臺北、新北各四架，重用已審查的客機模型，分不同相位、高度及速度飛行。移除原新北的兩架舊航班，避免重複。
- 船舶完整航線與船體餘裕檢查皆位於水面，避開兩座島、裝飾小島、橋梁、原有四艘船與其他船舶航線；飛機高度高於該市最高建築及國旗。停止動態／減少動態時，船、飛機與橋上車流均暫停。

政策內容與來源、街區分類、既有湖泊／地標／植栽／一般人車、國旗大小、Logo／介面與臺北預設視角均延續前版。

## 重建與檢查

```sh
python tools/plan_transport_v046.py    # 重新求解；修改既有布局後才需要
python tools/build_transport_preview.py
python tools/check_transport_plan_v046.py
python tools/check_transport_v046.py --no-screenshots
python tools/package_site.py
```

規劃器使用標準函式庫，結果提交於 `v046-transport-plan.json`，以 v044 布局檔與環境模組雜湊保護來源。CI 使用已提交的解，不重新搜尋。`transport-network-v046.js` 建立實際模型與動畫；新的 `street-infill-v046.js` 只增加橋頭走廊避讓，不改寫 v045 模組。

省略瀏覽器檢查的 `--no-screenshots` 可輸出雙橋電腦畫面及手機臺北首頁至 `out/v046-*.png`。檢查涵蓋橋頭節點、橋梁間距、不交叉、水域／船舶間距、實際場景數量、飛行高度、暫停／恢復、政策基地避讓與既有內容。
