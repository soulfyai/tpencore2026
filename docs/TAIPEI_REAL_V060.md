# 擬真臺北預覽 v0.6.0

獨立預覽，不替換正式網站，也不修改任何既有預覽。入口：`taipei-real-v0.6.0.html`（GitHub Pages 發布後為 `https://soulfyai.github.io/tpencore2026/taipei-real-v0.6.0.html`）。

## 這一版做了什麼

依使用者選定的「方案二」，臺北島改用擬真城市引擎，先做臺北市，新北市之後再接。

- **地理**：臺北市十二行政區實際邊界（內政部鄉鎮市區界線）、基隆河（含社子、關渡）、景美溪、雙溪；陽明山、內湖山區、四獸山、南港山、貓空以連續森林覆蓋。比例為真實比例（1 單位約 135 公尺），不放大島形。
- **城市**：每區有自己的街道方向、街廓大小與定位（信義金融、松山商務、南港與內湖科技、大同萬華老城、大安中正士林住宅、北投文山郊區）；101 周邊限高，讓 101 獨立突出。
- **地標**：101（含國旗）、大巨蛋、國父紀念館、中正紀念堂、總統府、台北車站、新光摩天大樓、小巨蛋、龍山寺、圓山大飯店、南港展覽館、臺大、陶朱隱園、美麗華、兒童新樂園、松山機場等，依真實經緯度放置並自動避讓。
- **政策園區**：17 個主題（9 政見＋8 政績）各一座園區，城市色外框、四角聚光燈、依主題配置建築。依主題放進合適的行政區，例如 AI 產業 → 北投（北士科）、居住都更 → 萬華、運動 → 松山（大巨蛋）。
- **渲染**：大氣天空與環境反射、ACES 色調、窗戶法線與粗糙度貼圖、接地暗部、夜間窗燈與店面燈、SSAO、泛光（夜景）、暗角。高畫質按鈕可關閉後製。

## 內容規則（沿用正式站）

- 資料只來自 `data/taipei.json`、`data/records-taipei.json`；政績分組與 `build.py` 相同（常數由 build.py 解析，不重複定義）。
- 每一項都附來源，建置時驗證；任何一項缺來源或引用不存在的來源，建置會失敗。
- 頁面保留「獨立整理，非任何候選人或政黨官方網站」與資料查核日；只用台北藍，不放黨徽、照片或官方標誌。

## 檔案

| 檔案 | 用途 |
|---|---|
| `prototypes/taipei-real-v060.js` | 擬真臺北引擎（three@0.160.0），`createTaipeiIsland(container, opts)` |
| `prototypes/taipei-real-v060.css` | 引擎樣式（限定在 `.tpi-root` 內），含政策標籤樣式 |
| `prototypes/taipei-real-v060-districts.js` | 十二行政區邊界 |
| `tools/build_taipei_real_preview.py` | 產生 `prototypes/taipei-real-v0.6.0.html`（內嵌資料） |

```sh
python3 tools/build_taipei_real_preview.py
```

`tools/package_site.py` 已加入此建置與四個檔案的發布。

## 引擎 API（預覽頁使用的部分）

| 參數／方法 | 說明 |
|---|---|
| `policies` | 主題陣列（含 `id`、`name`、`kind`、`area`、`no`、`items`） |
| `cityColor` | 園區外框與標籤色 |
| `onSelect(place)` | `place.type` 為 `district`、`landmark` 或 `policy`；`policy` 時含 `theme` 與所在行政區 |
| `focusPolicy(id)`、`setActivePolicy(id)` | 飛到主題園區、標示目前主題 |
| `focusOffset()` | 回傳鏡頭目標前移比例，手機底部面板用 |
| `landmarkLabels` | 預設關閉，避免與政策標籤搶畫面 |

除錯：`window.TAIPEI_REAL = { island, data, openTheme }`；`island.three` 可取得 scene、camera、controls。

## 驗證

本機以 three@0.160.0、Playwright＋swiftshader：
- 桌機 1280×800：載入無錯誤，17 個政策標籤，點標籤與清單都會開啟面板並飛到園區。
- 手機 390×844：載入無錯誤；開啟底部面板後，園區停在面板上方可見範圍。

## v0.6.1：正式站外殼＋擬真臺北

使用者要求：周邊 UI 不替換，唯一改變的是臺北市的美術設計與相對的政策標示位置。

- 入口 `greater-taipei-v0.6.1.html`，由 `tools/build_taipei_real_shell_preview.py` 從 `greater-taipei-v0.4.12.html`（正式站 2.2.x 的來源）複製產生，只做三處注入：
  1. 匯入 `taipei-real-v060.js`。
  2. 所有核准城市建好、交通網與原生標籤建立之前：隱藏 `approved-city-taipei` 與原台北國旗；以嵌入模式建立擬真臺北，等比例縮放進原台北島海岸外框；用正式站現有的 12 個台北政策主題建立園區，改寫 `isl.campus`、`isl.campusTop`、`body.anchor`、`ITEMS3D` 範圍與點選物件；臺北地標標籤移到新地標位置，新城市沒有的地標標籤移除。
  3. 每幀更新：擬真臺北動畫，並跟隨正式站的日夜狀態。
- 品牌、工具列、政策清單、泡泡、使用說明、時間模式、音樂、新北市、關渡與淡江大橋、海空交通與動物全部是正式站原樣。
- 引擎嵌入模式（`opts.embed`）：使用宿主 renderer，不建立畫布、天空、海、燈光、遠洋船隻與後製；海面以下的地形與樹冠三角形會被剔除，避免在宿主海面下露出方形。
- 已知差異：真實臺北海岸與原本風格化島形不同，雙橋落點與部分船隻航線是依原島形規劃，可能貼近或略微壓到新海岸。

## v0.6.2：新北市依真實地圖與臺北組合 {#v062}

使用者要求：新北市美術設計先不動，但依實際地理位置與行政區劃分，按真實地圖與臺北市組合（全部 29 區；關渡、淡江大橋移到淡水河真實位置）。

- 入口 `greater-taipei-v0.6.2.html`，由 `tools/build_greater_taipei_real_map_preview.py` 產生：沿用 v0.6.1 的全部注入（正式站 UI 不變、擬真臺北），再加上新北市的重新配置。
- 地理資料 `taipei-real-v062-newtaipei.js`（`tools/export_newtaipei_geo.cjs` 由內政部鄉鎮界線〔taiwan-atlas towns-10t〕投影到擬真引擎平面，1 單位≈135 公尺）：新北 29 區、新北外框與臺北市挖空範圍，另附基隆市外框（只當陸地，不放城市美術，避免出現假海灣）。
- 引擎 `opts.neighbor`：與臺北同一比例尺畫出周邊地形——新北陸地、淡水河、新店溪、大漢溪、基隆河上游，新北山區以連續樹林覆蓋；臺北盆地（三重、蘆洲、新莊、板橋、中和、永和、土城、樹林、大漢溪沿岸到三峽鶯歌、新店北側）、汐止、淡水市區維持平地。API 新增 `geo()`、`regionSample()`、`namedBridges()`。
- 新北城市美術仍由正式站的 `buildApprovedCityArt` 產生（同一套建築、街道、政策園區與地標模型、相同 1.8 單位街廓），只換掉輸入的規劃：街廓只鋪在真實新北的平地（避開河道、河岸與山坡，並自動選擇放得最多街廓的格網相位）；原本小島的沙地底座與草地拿掉，改由真實地形承接。
- 9 個新北政策主題放在對應的真實行政區附近（交通→板橋、居住→三重、托育→新莊、長者→永和、醫療→中和、教育→土城、產業→汐止、防災→蘆洲、族群→淡水；該區放不下時取最近的可用街廓）；5 個新北地標放在真實位置（新北市政府、淡水紅毛城、九份、十分、野柳）。
- 關渡大橋、淡江大橋由擬真引擎在淡水河真實位置建造，標籤跟著新位置；原本跨海峽的雙橋不再建造。
- 原本依小島海域規劃的船隻與海上裝飾，如果航線落到陸地上就隱藏；`coastal-surf` 海岸浪花隱藏。
- 已知限制：維持原美術比例的情況下，新北可鋪的平地街廓比原本小島少（真實新北多數是山地）；林口台地海拔約 230 公尺，與城市底座高度不同，暫不鋪街廓。

## v0.6.3：新北套用擬真美術、依衛星影像配置市區、山區路燈 {#v063}

使用者回饋：v0.6.2 的建築分布不準、很多區域被山林取代；新北要一起套用擬真美術；街廓不必死守比例，要呈現意象；山上也有人住，夜裡要有路燈。

- 入口 `greater-taipei-v0.6.3.html`，由 `tools/build_greater_taipei_region_preview.py` 產生；引擎 `taipei-real-v063.js`（v0.6.0～v0.6.2 仍用 `taipei-real-v060.js`，不受影響）。
- 區域模式（`opts.neighbor`）：城市視窗 440 單位（約 59 公里），涵蓋臺北、新北主要市區與基隆港；地形 521²（手機 441²）、地表貼圖 3072²（手機 2048²）。
- 行政區編號改為逐點掃描線填色（42 區，含基隆），不再靠畫布反鋸齒後的灰階推算。新北每區有自己的街道方向、街廓大小與性格：板橋新板特區高樓、新莊副都心、三重與永和老城、五股泰山工業區、林口台地新市鎮、淡水淡海、汐止河谷、北海岸與東北角小鎮；基隆市區只當景觀，不放政策內容。
- 已開發範圍 `dev`（經緯度多邊形＋地面海拔）依衛星影像描繪：新北的臺北盆地全區、林口台地（220 公尺）、鶯歌三峽、淡水淡海、八里、汐止、基隆、瑞芳、金山萬里三芝石門、深坑；範圍內地形整平到該海拔，範圍外依原本的山地與樹林。
- 新北 9 個政策主題與臺北 12 個一樣是擬真引擎的園區，外圈用新北市政黨色；放在交通→板橋、居住→三重、托育→新莊、長者→永和、醫療→中和、教育→土城、產業→汐止、防災→蘆洲、族群→淡水。新北的政策泡泡、點選範圍、項目範圍都改寫到新位置；原本新北美術群組隱藏。
- 新北地標由引擎建模在真實位置：新北市政府、淡水紅毛城、九份老街（山城與燈籠）、十分瀑布與天燈、野柳女王頭；淡水河、新店溪、大漢溪、基隆河上游加上一般橋梁，關渡、淡江大橋維持在真實位置。
- 山區道路：18 條實際路線（陽金公路、仰德大道、北海岸台 2 線、北宜、新烏、平溪線沿線、瑞金、雙溪貢寮等）以路點描述，引擎用 A* 依坡度與水域在地形上找路；路面畫進地表貼圖，樹冠讓出路廊；每 2.6 單位一盞路燈（燈桿＋夜間發光燈頭），地表另烘焙路燈照亮範圍的夜間發光；沿路與 18 個山區聚落（竹子湖、平溪、坪林、烏來、金瓜石、貓空等）放置民宅，夜間窗戶亮燈。
- 使用者圈選補充（同版）：北海岸帶（淡水丘陵、淡海、三芝、石門、金山、萬里到基隆）、淡水河西岸（八里、觀音山麓、林口外圍、五股泰山丘陵）、南側（樹林、土城與中和丘陵、三峽、鶯歌）也是市區。這些範圍用 `h=-1`「山坡聚落」：保留原地形但起伏降到 28%，整片作為市區，坡度門檻放寬，建築依地形高低座落。

- 已知差異：街廓大小為意象尺度，不是真實比例；臺北 12 個政策園區的位置因地形格網解析度改變，與 v0.6.1 略有不同（仍依同一套行政區對應表）。
