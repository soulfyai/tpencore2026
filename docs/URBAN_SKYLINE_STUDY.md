# 都市天際線建築範例 03

2026-10-25｜獨立美術範例，尚未替換正式網站或臺北預覽。

入口：<https://soulfyai.github.io/tpencore2026/skyline-study.html?rev=1>

## 目的

使用者指出臺北預覽第二版仍是相同的低樓小鎮風格，要求依新附城市建設遊戲畫面，展示真正不同的都市量體、建築群與高低混合。這次先用獨立範例區驗證語彙，不宣稱已完成臺北全島改造，也不複製參考遊戲的素材。

## 舊高度限制與新方向

臺北預覽 rev=2 的一般陽台公寓上限7層、一般辦公上限8層，另只安排少量10／15／20層高樓。這些出自 `taipei-preview.js` 的分配與截斷條件，是先前的美術／配置設定，不是 Three.js 的固定樓層上限。

原臺北預覽每格約14.4場景單位，舊建物占地約8×8。此範例的裙樓占地可達32×25，不能直接硬塞回舊單格；後續需要合併街廓、定義高樓核心與中低層過渡，並重新統一101及普通高樓的縮尺比例、鏡頭與標牌。樓高本身不等於引擎限制，窗格／細節的建模方式才決定模型量。

## 實際建築樣本

| 造型 | 範例樓層 | 主要差異 |
|---|---|---|
| 外露斜撐尖塔 | 塔身45F＋尖頂 | 結構斜撐、深藍玻璃、尖頂與裙樓 |
| 圓筒雙塔 | 38F／32F | 圓形平面、兩種高度、空中連廊及共用裙樓 |
| 斜冠玻璃高樓 | 48F量體 | 斜切冠頂與斜向結構 |
| 曲面玻璃辦公樓 | 36F | 圓角平面、連續曲面玻璃、水平樓帶 |
| 階梯式 Art Deco | 26F＋冠頂 | 石材感壁柱、深窗洞與逐級收分 |
| 錯位雙塔辦公群 | 35F／28F | 不同大小／錯位塔樓與連廊 |
| 退台式都會住宅 | 24F | 磚色立面、分段退台、屋頂綠化 |
| 商業辦公複合街廓 | 辦公6F＋裙樓 | 臨街商業、偏置辦公與遮棚 |
| 中層磚造圍合街區 | 10F | U形內院、連續街牆 |
| 弧頂文化場館 | 約5F量體 | 低而寬的曲面屋頂與玻璃前廳 |

另在前景保留低層住宅與小店，形成高／中／低的真實比例差異。樓層與造型均為本次示意，不是實際建案、法規核准或政策落實主張。45層尖塔含額外尖頂，模型總高度可高於48層平頂量體；最高配置樓層與最高模型尖端是不同概念。

## 操作與隔離

四個視角：都會全景、高樓輪廓、高低混合、水岸街區；可自由旋轉／縮放，點建築或透過建築目錄查看樣本與樓層。提供名牌、白天／夕陽及高／標準畫質。

新檔為 `prototypes/skyline-study.html`、`skyline-study.js`、`urban-buildings.js`，只延用既有預覽材質及低層組件；不修改正式兩版HTML、3d/、data/、street-test或臺北預覽rev=2。版本號維持2.0.18，沒有正式模型替換。NAS既有拉取腳本不下載新增預覽檔，測試入口在GitHub Pages。

`tools/check_skyline_study.py` 驗證真實WebGL畫面、10種樣本、48層配置、高度差異、目錄／拾取、鏡頭、光照、畫質、桌機／窄視窗及既有頁面未改；實際截圖在 `out/skyline-*.png`。

實作保留完整植栽，將重複接觸陰影合批；本機同畫面高畫質繪製呼叫由約1913減為615，幾何與植栽數量不變。這是繪製呼叫計數，並非使用者實機FPS量測。
