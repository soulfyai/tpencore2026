# 大台北範圍調整預覽

[開啟預覽](https://soulfyai.github.io/tpencore2026/greater-taipei.html?v=2)。此版本沿用正式站的地圖與介面，僅供確認；不替換正式網站，VERSION 維持 2.0.18。

## 沿用與調整

使用者要求優化迭代，已撤回先前重新製作圓形城市的方案。原臺北、新北海岸輪廓、相對位置、政策街區、政策主題位置、地標相對位置與操作方式沿用正式站，不以新概念島嶼替代。建築與街區的美術則使用後續確認的新版資產，原版視覺模型已從渲染場景撤下。

頁面名稱與品牌文字說明改為「大台北」，範圍只保留臺北、新北。初次進入與 Home 回到原生臺北市視角，全景仍可查看兩市。使用說明保持預設開啟。使用者最新確認以 tpencore.tw 正式介面為基準，Logo 圖檔、picture 響應來源、HTML 尺寸與所有正式 CSS 保持相同；撤除先前額外覆蓋的副標層。大台北名稱更新於頁面文字，既有招牌圖片不另行繪製。

政策資料保留臺北 17 主題、新北 9 主題，合計 118 個政見／政績條目。移除範圍外的城市介紹、選單及完整細節敘述，保留正確地名「基隆河、基隆路」與既有來源連結；原始資料不變。原 2D 設計另輸出為 greater-taipei-2d.html，使用同一雙市範圍。

預覽配置關閉 counter，不增加計數。其餘功能沿用原生實作。

入口沿用正式封裝的 UTF-8、lang 與 viewport 設定，手機使用實際裝置寬度，避免將桌機頁縮放到手機。

## 新美術與正式介面整合

介面與美術分開處理：`build_approved_city_art.py` 從已審查的 `taipei-city.js`、`regional-city.js` 提取實際場景建置，重用既有 kit/layout/roads/water/nature/life 模組，不載入這些樣板各自的工具列或 CSS。兩市沿用原有不規則海岸與地標位置，依原 scale=14 轉回正式世界座標。

保留機能對應的政策建築、高低混合建築與跨基地街廓、連通道路／整體路面材質、真實挖孔湖泊及橋、密植與民眾車輛。部分既有一般街廓加入 composition v2 的實際騎樓、四面窗框／陽台、屋頂設備及店面模型，仍在原基地內。客船與帆船重用 composition 的船模，沒有匯入它的另一座島嶼輪廓。兩市最高模型上的中華民國國旗保留。

`greater-taipei-art-bridge.js` 僅作世界座標、原生政策拾取／標牌焦點、人車動態及渲染相容處理；不建立新的產品介面。日／夜／實際時間仍由原 ENV 控制。新增材質反射、接觸陰影與無貼片框背景雲。既有公版 Logo 圖像含原副標，依本次「Logo 不變」要求保留。

## 建置與驗證

```sh
python3 tools/package_site.py
python3 tools/check_greater_taipei.py
python3 tools/check_greater_taipei_mobile.py
```

建置器在暫存目錄複製正式來源後修改，不直接寫入正式 3d/、data/、template.html。使用原版匯出的 coast、cell、theme 配置鎖定兩市幾何，避免刪除另外兩市時重新計算布局。

WebGL 檢查直接載入正式 index3d.html 與預覽，比對兩市所有海岸座標、完整街區多邊形／主題指派、主題中心、政策街區指派與主題中心，容差 1e-8；新版模型的高度與包圍盒依新美術更新，不再要求等於舊模型。另比對所有正式 CSS、Logo picture 的完整內容、桌機／手機實際 Logo 矩形均相同；另驗證臺北預設視角、兩市數量、內容範圍、預設說明、主題面板、手機寬度與瀏覽器錯誤。實拍在 out/preserved-*.png。

封裝只發布 greater-taipei.html、greater-taipei-2d.html、greater-taipei-config.json 預覽檔及兩個美術資源檔。NAS 原更新腳本不下載這些獨立入口。正式首頁的內容須與此次更改前保持相同；確認後才能規劃正式替換。
