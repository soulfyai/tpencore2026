# 橋梁接岸美術修整 v0.4.7

以 v0.4.6 為基準，修正兩座橋四個接岸處與橋梁本體的收邊，不替換正式首頁、不改動既有介面與臺北預設視角。

## 接岸與橋梁收整

- 四個接岸處改為完整三向街口，以同一個精確邊界切除舊瀝青、人行道與路緣，再鋪回彼此不重疊的路面與人行道。
- 直接沿用街道的瀝青、鋪面材質與原有標線位置；接岸的紋理 UV 以各市原座標對齊。
- 橋面與街道以相同高程接合。坡道採零斜率、零二階導數的平順過渡，標線改為與瀝青同層繪製，避免浮起、插入路面或深度閃動。
- 兩側補齊人行道、路緣、封閉梁側及梁底；護欄留在人行道範圍內，以實體圓角端座收頭，不伸入路口。
- 橋台依實際沙岸外緣裁切，承座與翼牆埋入岸坡，移除原本固定放在岸邊的巨大橋墩。橋墩只放在水域的結構支點。
- 調整拱腳座、吊桿與斜張索錨座，使構件有實體接合；白色橋塔旁增加行人繞行空間，塔腳避開車道。
- 車輪依實際模型最低點貼路，車身依坡度調整，消除原有懸空高度。

原有街區、地標、湖泊、植栽、國旗、24 艘船、8 架飛機與16 輛橋上車均保留。

## 來源、重建與檢查

`v047-bridge-finishes.json` 保存四個街口、精確分區三角形與沿岸橋台裁切結果，雜湊綁定原布局與 v046 橋梁計畫。離線匯出使用 Shapely 2.1+；正式網站及 CI 不需要這項依賴，也不重新求解。

```sh
# 僅改動來源布局後需要重新匯出：
python tools/export_bridge_art_v047.py
python tools/build_bridge_art_preview.py
node tools/check_bridge_art_v047.mjs
python tools/check_bridge_art_browser_v047.py
python tools/package_site.py
```

幾何檢查直接使用既有道路工廠，核對四處的面積與單一鋪面所有權、舊路緣移除、同高程與緩坡接合、護欄收頭、水域橋墩、同層標線、向上路面法線及數值有效性。瀏覽器檢查輸出四處實際手機／電腦近景至 `out/v047-*.png`，並保留原有內容與交通檢查。
