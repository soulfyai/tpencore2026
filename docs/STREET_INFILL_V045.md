# 街區補齊、植栽與國旗預覽 v0.4.5

入口：`greater-taipei-v0.4.5.html`。以 v0.4.4 為基礎的獨立預覽，正式首頁、v0.4.4 和以前的版本保持不變。

## 本次修正

- **補齊街格**：原先規劃器使用地標的寬鬆避讓圓，臺北 160 個格點只有 78 個分配到政策／公園等基地，導致周邊街格留空。新流程逐一檢查實際地標幾何占用範圍，在可用街格放置完整或偏移的較小建築，避開道路、湖泊、自然地標和既有園區。
- **多種建築**：臺北新增 36 棟、新北新增 16 棟，合計 52 個不同結構描述，涵蓋既有美術庫的 24 種量體。包含庭院住宅、退台商樓、拱頂圖書館、鐘樓、玻璃中庭、街屋與商廊；顏色、樓高、屋頂及立面細節各異。新增街區不增加政策泡泡。
- **加密樹群**：改用兩輪交錯的密植網格及較豐滿的樹冠，從沿岸、湖邊延伸到可種植的街角與地標周邊。新增一般植栽臺北 1,960 棵／新北 1,216 棵（上一版 207／188），另保留自然地標原有植栽。樹冠避開海岸、水面、道路及建築基地。
- **放大國旗**：旗面從約 2.5 × 1.65 放大到 12.6 × 8.4 個美術場景單位，旗桿同步增高至 15.7。使用 3:2 畫布、正確青天白日圖案、雙面材質與輕微飄動，夜間略增自發光；仍固定在各市最高建築屋頂。減少動態時停止飄動。

政策分類、內容、來源、已完成狀態、地標與海岸位置、道路路網、湖泊、人車、Logo／介面及預設／全景相機均沿用 v0.4.4。新增建築屬街景示意，非實際建設或承諾。

## 主要檔案

- `prototypes/street-infill-v045.js`：實際地標占地、街格填補、密植與國旗。
- `tools/build_street_infill_preview.py`：由 v0.4.4 輸出新檔，不覆寫基準版本。
- `tools/check_street_infill_v045.py`：實際 WebGL 建築數／多樣性、可建築空格、完整邊界、植栽量、旗面比例、政策閱讀與電腦／手機截圖。

```sh
python tools/build_street_infill_preview.py
python tools/check_street_infill_v045.py --no-screenshots
python tools/package_site.py
```

省略 `--no-screenshots` 可輸出 `out/v045-*.png`。已保留的湖泊、自然地標、廣場和交通道路不視為待蓋滿的空區。
