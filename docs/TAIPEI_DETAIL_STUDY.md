# 臺北生活街區・實際 3D 美術樣板

使用者希望縮小生成示意圖與實際 Three.js 模型的美術落差。本輪先做一個獨立街區驗收，並不替換正式城市或之前已確認的四市預覽。

入口：[taipei-detail.html?v=1](https://soulfyai.github.io/tpencore2026/taipei-detail.html?v=1)。此頁實際生成幾何、材質、燈光與陰影，可原生旋轉、縮放和平移；沒有以生成圖片當作場景背景或建築替身。

## 本輪製作

- 赤陶街角住宅、青綠退台住宅、米白窄塔、紅磚老街樓，採不同高度、占地、朝向與輪廓。立面加入有厚度的窗框、窗台、陽台、細欄杆、植栽、冷氣設備；屋頂有女兒牆、設備、太陽能板與退台。
- 五個店面有招牌、凹入玻璃櫥窗、陳列、條紋遮棚、盆栽與騎樓柱列；咖啡座、書店及麵包店是美術示意，非真實店家。
- 托育館採三翼圍合、木百葉、深入口雨棚、坡道、矮圍籬與庭院遊具。玻璃辦公樓另有垂直遮陽、水平帷幕、裙樓與植栽露台。
- 臺北101保留逐節塔身與屋頂中華民國國旗，為本樣板最高地標。
- 地形實際挖出不規則湖面，沿岸石塊、蘆葦、曲線步道、木棧板、欄杆與長椅。草地、鋪面、磁磚、瀝青使用實際 canvas 材質，葉片、花朵與生活設施可近看。
- 四個視角、白天／夕陽、畫質與動態控制。預設不自動移動，以利比較；開啟動態後有少量車輛與揮手、水面變化。獨立示意場景，沒有新增政策承諾、帳號或追蹤。

## 驗收

執行 `tools/check_taipei_detail.py`，實際檢查桌機／手機原生操作、四視角、時間與畫質切換、模型清單及正式檔案未變。截圖在 `out/detail-*.png`。瀏覽器截圖即為交付畫面，不以生成圖替代驗收。

本頁是局部材質與建築細節樣板，尚未完成全市美術重製；其模型細節與生成示意圖之間仍需使用者逐輪評估。正式VERSION保持原值。NAS原更新器不下載此新獨立檔，使用GitHub Pages連結檢視。
